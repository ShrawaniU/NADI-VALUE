# NADI-VALUE Dataset

## Photos used for prototype training

Training photos:
`dataset/images/train/`

Validation photos:
`dataset/images/val/`

YOLO labels:
`dataset/labels/train/`
`dataset/labels/val/`

Classes:
0 = idol
1 = plastic
2 = cloth
3 = flower

This repository contains a very small starter dataset for pipeline/prototype testing. It is NOT a reliable accuracy benchmark.
Some starter images were sourced from previously collected prototype material and may contain visible stock-image watermarks. Replace them with photos you own or have a suitable license to use before public/commercial reuse.
Review the bounding boxes in LabelImg before final training.
