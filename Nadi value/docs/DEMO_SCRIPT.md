# 90-second demo

"River festivals can leave idols and puja-related materials in water. The problem is not only pollution; materials that still have recovery value become mixed waste.

This is NADI-VALUE.

The camera image is processed by a YOLO11 detector. It identifies four practical categories: idol, plastic, cloth and flower.

The important second step is recovery routing.

Plastic goes to recycling.
Flowers go to composting.
Cloth goes to reuse or textile recovery.
Idols go to a safe material-recovery pathway.

The model is exported to ONNX and the Windows application is designed to use Qualcomm QNN when available, so the intended deployment is local inference on Snapdragon-powered HP PCs.

The project therefore connects AI detection with a simple operational action: detect the material, prevent disposal, and route it toward recovery instead of treating everything as waste."

Then show one image and the detection window.
