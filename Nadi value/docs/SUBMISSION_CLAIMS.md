# Safe Submission Claims

Use these claims:

- NADI-VALUE is an AI-powered river-waste detection and recovery assistant.
- It detects four categories: idol, plastic, cloth and flower.
- The detector is based on YOLO11.
- The model is exported to ONNX for deployment.
- The Windows application can select QNNExecutionProvider when available.
- The deployment is designed for Snapdragon-powered HP PCs.
- The solution is local/on-device in its intended deployment path.

Do not claim:

- "tested on Snapdragon HP" unless actually tested.
- "NPU latency is X ms" unless measured on the actual target device.
- "the system detects water contamination" because no water-quality sensor is included.
- exact monetary value of recovered waste without local data.
- that an ASUS laptop provides Qualcomm NPU acceleration.

Qualcomm AI Hub's published YOLOv11 reference jobs are reference-device measurements, not measurements of this project.
